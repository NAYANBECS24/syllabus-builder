Industrial-strength document reconstruction for complex university syllabi. Discovers document grammar at runtime, parses course boundaries, topics, Bloom taxonomy levels, and CO-PO articulation matrices word-for-word into verifiable JSON schemas with zero hallucinations.

PIPELINE: Triage → Grammar Induction → Segmentation → Deep Extract → Consensus Gate → JSON Schema
Document Grammar Induction
Learns layout typography, unit keywords, code styles, and matrix symbol sets at runtime directly from document structure.
Lossless Topic Segmentation
Hierarchical 7-strategy delimiter cascade with closed-world source reconstruction invariants for 100% complete coverage.
Bloom Cognitive Taxonomy
Extracts explicit printed markers (K1–K6, BT1–BT6) as printed, backed by a 40+ cognitive action-verb classifier.
CO-PO Matrix Alignment
Dual-backend table fusion stitches multi-page matrices, aligns PO headers, and preserves source symbols (S/M/L, 1/2/3).
Grounded Bibliographic Parser
Right-to-left slot decomposition isolates title, author, edition, publisher, and publication year without hallucinations.
Honest not_extracted Ledger
Auditable accounting of absent or unresolvable document regions to guarantee that evaluated outputs never fabricate data.
